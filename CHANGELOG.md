# Changelog

## 3.1.1

### Ядро

- `peerDependencies.typescript` расширен с `^5` до `>=5`: с TypeScript 7 npm отказывался
  ставить пакет (ERESOLVE на опциональном peer). Библиотека проверена на TypeScript 7.

### Экосистема

- **`@rwcjs/router` 0.1.0** — роутер на сигналах. Параметры типизируются из строки
  пути (`"/users/:id"` → `params().id: string`), переход между `/users/1` и `/users/2`
  не пересоздаёт страницу, побеждает самый специфичный маршрут. History API или hash,
  `base`, ссылки с активным состоянием, `url` для серверного рендера. Маршрут без `*`
  всегда сильнее маршрута с хвостом, дальше сравниваются сегменты по порядку.
- **`@rwcjs/forms` 0.1.0** — формы на сигналах. Имена и типы полей выводятся из
  начальных значений, ошибка показывается после ухода с поля или попытки отправки,
  `bind()` связывает поле с инпутом одной строкой (value, checked или число), есть
  `submitting`, защита от двойной отправки и ошибки от сервера через `setErrors`.
  Набор `validators`: required, minLength, maxLength, pattern, email, sameAs.
- **`@rwcjs/create` 0.1.0** — генератор проектов: `npm create @rwcjs@latest my-app`.
  Шаблон `app` — приложение на Vite с роутером, формой и примером компонента; шаблон
  `library` — библиотека компонентов с типами и Custom Elements Manifest. Оба шаблона
  проверяются typecheck'ом репозитория.
- **Сайт документации** на VitePress (`site/`): английская и русская версии из `docs/`,
  страницы пакетов из их README, живые примеры, поиск; деплой на GitHub Pages.
- js-framework-benchmark: реализация оформлена по правилам репозитория бенчмарка,
  проверка `isKeyed` пройдена.

## 3.1.0

### Ядро реактивности

- **Ленивый `computed` без промежуточных состояний (push-pull).** `computed` вычисляется
  при чтении, запоминает результат и пересчитывается, только если источники
  действительно изменились. Пересчёт в равное значение (`Object.is` или новая опция
  `equals`: `computed(fn, { equals })`) наблюдателей не будит. В ромбе
  `a → (b, c) → d` эффект видит `b` и `c` согласованными, сколько бы уровней
  `computed` ни было между ними.
- **`computed` не нужен владелец.** На источники он подписан, лишь пока его читает
  эффект, и сам отписывается, когда эффекты умирают, — поэтому не течёт и
  объявляется где угодно: в `render()`, в модуле, в сторе.
- **`computed` внутри `batch` актуален** — он пересчитывается при чтении, а не
  ждёт выхода из группы.
- `createComputed(compute, options?)`: второй аргумент теперь — опции сигнала.
  Функция-фабрика эффекта в этой позиции игнорируется ради совместимости.
- **`createSelector(source, equals?)`** — проверка «ключ выбран?» за O(1): при смене
  выбора просыпаются только старый и новый ключ, а не все читатели.
- **`effect()` в `render()` принадлежит компоненту.** Раньше эффект, созданный обычным
  `effect()` прямо в `render()`, не попадал к компоненту и переживал его отключение —
  утечка. Теперь такой эффект (как и созданный в `createRoot`, `when`, `each`)
  забирает текущий компонент или скоуп.

### Компоненты

- **Перемещение без перерисовки.** Уборка отключённого компонента отложена на
  микрозадачу: если элемент вставили обратно в том же такте (`insertBefore`,
  перестановка в `each`, перенос в портал), ничего не пересоздаётся — фокус,
  введённый текст и скролл сохраняются. Компоненты реализуют `connectedMoveCallback`,
  а `each` переставляет узлы через `Element.moveBefore()`, где браузер его умеет.
- **Атрибуты разбираются по типу пропса.** Булев проп — как в HTML: есть атрибут —
  `true`, `"false"` или снятый атрибут — `false`. Числовой — через `Number()`,
  нечисло откатывается к начальному значению. Строковый получает строку как есть.
  Остальное (объекты, массивы, `null`) по-прежнему разбирается как JSON.
- **`reflect`** — `defineComponent({ props, reflect: ["disabled", "variant"] })`
  зеркалит пропсы в атрибуты хоста для `:host([disabled])`. То же самое — `static reflect`.
- **Компоненты для форм.** `defineComponent({ ..., form: true })` включает
  `formAssociated` и `attachInternals`. Появились `this.internals`,
  `this.setFormValue(value)` (с сигналом или функцией держит `FormData` в актуальном
  состоянии), сигнал `this.formDisabled` и переопределяемый хук `formReset()`,
  который по умолчанию возвращает пропсы к начальным значениям. Экспортирован тип
  `FormValue`.
- **Пропсы — DOM-свойства.** Для каждого пропса на элементе есть аксессор:
  `el.value = 5` пишет в сигнал, `el.value` читает. Так компонентами управляют React 19,
  Vue, Angular и Svelte. Значение, выставленное до регистрации класса, подхватывается
  при upgrade. Имена членов `HTMLElement` (`title`, `hidden`, ...) не перекрываются.
- **Серверный рендер.** `renderToString(build, options?)` сериализует разметку в HTML
  с Declarative Shadow DOM и стилями компонентов. См. `docs/*/ssr.md`.
- Новые фабрики тегов: `thead`, `tbody`, `tfoot`, `caption`, `colgroup`, `col`, `dl`,
  `dt`, `dd`, `menu`, `fieldset`, `legend`, `optgroup`, `datalist`, `output`, `address`,
  `hgroup`, `dialog`, `template`, `abbr`, `dfn`, `q`, `kbd`, `samp`, `time`, `bdi`, `bdo`,
  `wbr`, `picture`, `source`, `track`, `iframe`, `embed`, `area`.

### Изменения поведения

- **Уборка при отключении отложена.** Эффекты и разметка компонента уничтожаются не
  в `disconnectedCallback`, а на микрозадаче после него. Тесты, которые проверяют
  уборку сразу после `remove()`, должны сначала подождать:
  `await new Promise((r) => setTimeout(r, 0))`.
- **Строковые пропсы больше не разбираются как JSON**: `label="42"` даёт `"42"`, а не
  `42`. Булевы пропсы следуют HTML: пустой атрибут (`<x-switch disabled>`) теперь
  `true`, а не `""`.
- **`computed` ленивый**: он не вычисляется, пока его не прочитали, и больше не
  выполняется как немедленный эффект. Побочные эффекты внутри `compute` (которых там
  быть не должно) срабатывают только при чтении.

## 3.0.0

Библиотека переписана с нуля. Идея прежняя — сигналы, фабрики тегов, веб-компоненты
без шаблонов и JSX, — но ядро, владение эффектами и списочный рендер сделаны заново.

### Ядро реактивности

- **Очередь эффектов вместо пересоздания подписчиков.** `set` больше не уничтожает
  подписчиков с последующим воссозданием через микрозадачу: изменения копятся в `Set`
  и разбираются одним проходом. Ромб зависимостей даёт один прогон вместо двух,
  а DOM обновляется синхронно — сразу после `set` разметка уже актуальна.
- **`batch`** — группировка записей: подписчики просыпаются один раз на выходе.
- **`untracked`** — чтение без подписки.
- **Вложенные эффекты.** `effect` внутри `effect` больше не ошибка: вложенный эффект
  становится ребёнком родителя, умирает при его перезапуске и создаётся заново.
  Уничтожение родителя каскадом уносит всё поддерево.
- **`onCleanup` и `onDispose` разделены**: первый выполняется перед каждым следующим
  прогоном, второй — только при уничтожении эффекта.
- **`peek()`, `update(fn)` и опция `equals`** у сигнала. Сравнение по умолчанию —
  `Object.is`; `equals: false` будит подписчиков на каждую запись.
- **Предохранитель от цикла**: эффект, который сам себя будит, падает с внятной
  ошибкой вместо зависания страницы.
- **`derived`** — производное значение без запоминания и без эффекта, дешевле `computed`.

### Разметка

- **`each` с ключами** переписан на честный diff через наибольшую возрастающую
  подпоследовательность: узлы переиспользуются, перестановка двух соседей двигает
  только их. В рендер приходят сигналы элемента и индекса, поэтому смена данных
  обновляет содержимое, а не пересоздаёт узлы.
- **Блоки не оборачивают содержимое.** `when`, `each` и `dynamic` держат место
  комментариями-якорями — селекторы `ul > li` и `:nth-child` продолжают работать.
- **Функция — реактивный источник** везде, где значение не может быть функцией:
  дети, `attrs`, `style`, `.свойства` HTML-элементов. `span(() => count())`
  равнозначно `span(count)`, а `computed` для этого больше не нужен.
- **`null`, `undefined` и `false` среди детей пропускаются** — работает `cond && span("x")`.
- **`class` со счётчиком ссылок на токен**: несколько источников одного класса
  не гасят друг друга, а токен не исчезает из `classList` даже на мгновение,
  чтобы не перезапускались CSS-переходы.
- **`show`** — переключение видимости через `display`, не трогая DOM и эффекты.

### Компоненты

- **`shadow: "open"` по умолчанию**, режим и опции задаются в `defineComponent`
  или через `static shadowOptions`.
- **`static styles` и тег `css`**: CSS разбирается один раз и раздаётся экземплярам
  общим `CSSStyleSheet` через `adoptedStyleSheets`.
- **Контекст `provide`/`inject`** с типизированными ключами `createContext`. Поиск идёт
  вверх по дереву через границы shadow, а вернувшийся сигнал связан с провайдером
  напрямую, без промежуточных событий.
- **Типизированные scoped-слоты**: `slots` в объявлении компонента, `#имя` при вызове
  фабрики, `this.renderSlot(name, ctx, fallback)` в разметке.
- **`configCustomComponent`** разделяет объявление и регистрацию и поддерживает
  постфикс тега — несколько версий UI-кита уживаются на одной странице,
  а вызовы фабрики не меняются.
- **`createComponent`** — функциональные компоненты, принимающие `class`/`attrs`/`style`/`show`
  наравне с фабриками тегов.
- **`createRoot`** — владелец эффектов для кода вне компонентов: точки входа, модульного
  состояния, тестов.

### Асинхронность

- **`resource`** вместо `createSignal(promise)`: даёт `data`, `loading`, `error` и `refetch`,
  перезапрашивает при изменении зависимостей, отменяет предыдущий запрос через
  `AbortSignal` и игнорирует ответ, который уже неактуален.
- **`firstUpdate`** срабатывает на первое изменение источника, а не на начальное значение.
- **`rs`** — реактивные шаблонные строки, **`combine`** — несколько источников кортежем.

### Несовместимые изменения

- Пакет переписан целиком, публичный API другой. Прямого пути обновления с 2.x нет.
- Декораторы `@component`, `@property`, `@event` убраны — компонент объявляется через
  `defineComponent({ props, events, slots })`, который выводит типы пропсов и событий.
- Роутер убран.
- `getList` заменён на `each`, `rootStyle` — на `static styles`.
- `forkJoin` и `combineLatest` заменены одним `combine`.
- `signal.pipe`, `setName`, `getSubscribers`, `forceSet` убраны: сигнал несёт только
  `set`, `peek` и `update`.
