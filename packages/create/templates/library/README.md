# rwc components

A component library created with `npm create @rwcjs -- --template library`.

```bash
npm install
npm run dev     # demo page from index.html and demo/
npm run build   # dist/ with types, plus custom-elements.json
```

- `src/button.ts`: a component with props, an event, reflected attributes and styles.
- `src/index.ts`: the public API. Components are declared with `configCustomComponent`,
  and the consuming app registers them with `registerAll()`.
- `custom-elements.json`: the manifest for editors, Storybook and framework wrappers,
  generated by `@rwcjs/cem-plugin`.

Using the library in an app:

```ts
import { registerAll, uiButton } from "rwc-components";

registerAll();
document.body.append(uiButton({ ".variant": "primary" }, "Save"));
```

`@rwcjs/core` is a peer dependency, so the app and every library share one copy of it.
