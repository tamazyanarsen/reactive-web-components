## Сигналы

### `signal(initValue, options?)`

Создаёт изменяемый источник.

```ts
const count = signal(0);
const items = signal<string[]>([], { equals: false });
```

| Член | Сигнатура | Описание |
| --- | --- | --- |
| вызов | `(): T` | значение; внутри эффекта создаёт подписку |
| `set` | `(value: T): void` | запись; равное значение подписчиков не будит |
| `update` | `(fn: (prev: T) => T): void` | запись от предыдущего значения, чтение без подписки |
| `peek` | `(): T` | значение без подписки |

`options.equals` — сравнение старого и нового значения. По умолчанию `Object.is`.
`false` отключает сравнение: подписчики просыпаются на каждую запись.

### `batch(fn)`

Группирует записи: подписчики выполняются один раз после выхода. Возвращает
результат `fn`. Вложенные `batch` разбираются на выходе из внешнего.

### `untracked(fn)`

Выполняет `fn` без подписки на прочитанное и без передачи владения созданным
внутри эффектам. Возвращает результат `fn`.

### `isSignal(value)`

Проверяет бренд реактивного источника. `true` для `signal`, `computed`,
`derived`, `rs`, `combine`; `false` для обычной функции.

## Эффекты

### `effect(fn): EffectCb`

Выполняет `fn` сразу и при каждом изменении прочитанного. Возвращает ручку с
методом `destroy()`.

Эффект, созданный внутри прогона другого, становится его ребёнком: уничтожается
перед перезапуском родителя и вместе с ним.

### `onCleanup(fn)`

Регистрирует уборку перед следующим прогоном текущего эффекта и при его
уничтожении. Вне эффекта — ничего не делает.

### `onDispose(fn)`

Регистрирует уборку только на уничтожение эффекта. Работает лишь на первом
прогоне; вызов позже выводит предупреждение.

## Производные значения

### `computed(fn)`

Производное значение с запоминанием. Пересчёт живёт на эффекте, который
принадлежит текущему компоненту (а вне компонента — самому себе).

### `derived(fn)`

Производное значение без запоминания и без эффекта: `fn` выполняется на каждое
чтение. Дешевле `computed` для коротких выражений, ничего не требует уничтожать.

### `createComputed(compute, createEffect?)`

Низкоуровневый конструктор: позволяет задать, кто создаёт эффект пересчёта.
Прикладной код использует `computed`.

### ``rs`строка` ``

Реактивная строка. Значения — статика, сигналы или обычные функции.

```ts
const label = rs`btn btn-${size} ${() => (active() ? "on" : "off")}`;
```

### `combine(...sources)`

Собирает источники в кортеж; чтение подписывает на все сразу.

```ts
const [width, height] = combine(widthSignal, heightSignal)();
```

## Фабрики тегов

Именованные фабрики: `div`, `span`, `section`, `article`, `aside`, `nav`,
`header`, `footer`, `main`, `slot`, `p`, `h1`–`h6`, `strong`, `em`, `b`, `i`,
`u`, `s`, `small`, `mark`, `sub`, `sup`, `del`, `ins`, `blockquote`, `cite`,
`pre`, `code`, `br`, `hr`, `form`, `input`, `textarea`, `button`, `label`,
`select`, `option`, `progress`, `meter`, `ul`, `ol`, `li`, `table`, `tr`, `td`,
`th`, `a`, `img`, `audio`, `video`, `canvas`, `figure`, `figcaption`, `details`,
`summary`.

```ts
div(config?, ...children)
div(...children)          // конфиг можно опустить
```

### `el(tagName, config?, ...children)`

Фабрика с произвольным тегом — для тех, которых нет среди именованных.

### `appendChildren(parent, children)`

Добавляет детей по общим правилам (реактивный текст, пропуск пустых значений).

### `buildFragment(content)`

Собирает `FlowContent` во фрагмент теми же правилами.

## Конфиг элемента

| Ключ | Тип | Описание |
| --- | --- | --- |
| `.свойство` | `MaybeReactive<T>` | пишет в DOM-свойство; свойства-функции исключены типом |
| `@событие` | `(event) => void` | слушатель; тип события и `currentTarget` выведены |
| `class` | `ClassValue` | классы, см. ниже |
| `attrs` | `Record<string, MaybeReactive<AttrValue>>` | атрибуты |
| `style` | `Record<string, MaybeReactive<StyleValue>>` | инлайновые стили |
| `show` | `MaybeReactive<boolean>` | переключение через `display` |

**Атрибуты.** `null`/`undefined` снимают атрибут; `false` тоже снимает, `true`
ставит пустой (как `disabled`). Исключение — `aria-*`: там пишутся буквальные
`"true"`/`"false"`, потому что отсутствие `aria-checked` не то же самое, что
`aria-checked="false"`.

**Стили.** Ключ — camelCase, kebab-case или `--custom-property`. Пустая строка,
`null` и `undefined` снимают свойство. CSS-переменные сохраняют регистр.

**show.** Запоминает инлайновый `display`, который был до скрытия, и возвращает
его при показе.

У веб-компонентов дополнительно доступен ключ `#имяСлота` — шаблон слота.

## Классы

`ClassValue` — строка, `false`/`null`/`undefined`, функция-источник, объект
условий, `cls`-конфиг или массив всего перечисленного.

```ts
class: "card"
class: ["card", "wide"]
class: ["tab", { active: isActive, disabled: () => !enabled() }]
class: cls`btn btn-${size}`
```

### ``cls`строка` ``

Шаблонный тег, возвращающий конфиг: `div(cls`card ${theme}`)`. Написанное слитно
склеивается в один токен (`btn-${size}` → `btn-lg`), разделённое пробелом
остаётся разными токенами. Разворачивается спредом рядом с другими ключами:
`div({ ...cls`card`, ".id": "x" })`.

Каждый источник владеет своими токенами: общий класс держится, пока его не
отпустят все.

### `applyClass(element, value)`

Применяет `ClassValue` к готовому элементу.

## Управление потоком

### `when(condition, renderTrue, renderFalse?)`

Условный рендер. Ветка пересобирается только при смене истинности условия.
Содержимое снятой ветки уничтожается вместе с эффектами. Возвращает фрагмент.

### `dynamic(render)`

Реактивный участок: пересобирается при изменении любого сигнала, прочитанного
прямо в `render`. Эффекты, созданные внутри, живут в скоупе блока и в его
зависимости не попадают.

### `each(source, renderItem, getKey?)`

Списочный рендер с переиспользованием по ключу. В `renderItem` приходят сигналы
элемента и индекса. Ключ по умолчанию — сам элемент; для объектов передавайте
`getKey`. Повторяющиеся ключи вызывают предупреждение, такие записи
пересоздаются на каждое обновление.

Блоки не оборачивают содержимое в дополнительный элемент.

## Компоненты

### `defineComponent(config)`

Возвращает абстрактный класс. Наследник реализует `render(): FlowContent` — элемент,
фрагмент, массив узлов или пусто; корневая обёртка не обязательна.

| Поле конфига | Тип | Описание |
| --- | --- | --- |
| `props` | `Record<string, unknown>` | начальные значения; задают типы и наблюдаемые атрибуты |
| `events` | `Record<string, unknown>` | имена событий; значение задаёт тип payload |
| `eventOptions` | `Record<string, EventOptions>` | `bubbles`, `composed`, `cancelable` на событие |
| `slots` | `Record<string, unknown>` | слоты; значение задаёт тип контекста |
| `shadow` | `"open" \| "closed" \| ShadowRootInit` | режим теневого корня, по умолчанию `open` |
| `styles` | `ComponentStyles` | CSS компонента |

Имена атрибутов и событий — kebab-case от ключа: `maxCount` → `max-count`,
`valueChange` → `value-change`. Значение атрибута разбирается `JSON.parse`,
а что не разобралось — остаётся строкой. Снятие атрибута возвращает проп к
начальному значению.

### `payload<T>()`

Фантомное значение: задаёт тип payload события или контекста слота, в рантайме
ничего не создаёт.

### Члены компонента

| Член | Описание |
| --- | --- |
| `props` | объект сигналов |
| `events` | объект эмиттеров: `this.events.change(value)` |
| `renderSlot(name, context, fallback?)` | рендерит слот; возвращает фрагмент |
| `provide(key, value)` | кладёт значение в контекст поддерева |
| `inject(key)` | берёт значение из ближайшего провайдера |
| `addEffect(fn)` | создаёт эффект, принадлежащий компоненту |
| `shadow` | теневой корень (`protected`) |
| `static styles` | CSS компонента |
| `static shadowOptions` | опции теневого корня |
| `static renderTagName` | тег, под которым компонент зарегистрирован |

### `useCustomComponent(component, tagName)`

Регистрирует компонент и возвращает фабрику.

```ts
const counter = useCustomComponent(Counter, "x-counter");
counter({ ".value": 5, "@change": (e) => e.detail }, "дети");
```

### `configCustomComponent(component, baseTagName)`

Возвращает `[factory, register]`. Фабрика до регистрации бросает ошибку.

```ts
const [UwcButton, registerUwcButton] = configCustomComponent(Button, "uwc-button");
registerUwcButton({ postfix: "moduleA" }); // <uwc-button-modulea>, возвращает имя тега
```

Постфикс приводится к нижнему регистру. Повторная регистрация тем же тегом
безопасна; попытка сменить тег выводит ошибку — один класс живёт под одним тегом.

### `createComponent(render)`

Функциональный компонент. `render` получает пропсы и детей, возвращает корневой
элемент; обёртка применяет к нему `class`, `attrs`, `style` и `show` из пропсов.

```ts
const Card = createComponent<{ title: string }, HTMLElement>((props, ...children) =>
  section(cls`card`, h3(props.title), ...children),
);
```

## Стили

### ``css`...` ``

Шаблонный тег для CSS. Текст не меняет — нужен для подсветки и форматирования.

### `ComponentStyles`

`string | CSSStyleSheet | ReadonlyArray<string | CSSStyleSheet>`.

Строки кэшируются: одинаковый CSS даёт один `CSSStyleSheet` на всю страницу,
общий для всех экземпляров. Без поддержки конструируемых таблиц стилей
используется запасной путь через `<style>`.

### `adoptStyles(root, styles)`

Вешает стили на теневой корень; возвращает узлы, которые нужно вставлять в
разметку на запасном пути.

## Контекст

### `createContext(name, defaultValue?)`

Ключ контекста. Со значением по умолчанию `inject` всегда возвращает `T`, без
него в тип попадает `undefined`.

### `provideOn(node, key, value)` / `injectFrom(node, key)`

То же, что методы компонента, но для произвольного узла. `injectFrom` ищет
ближайшего провайдера вверх по дереву, пересекая границы shadow; поиск ленивый,
найденный сигнал запоминается.

## Асинхронность

### `resource(fetcher, options?)`

```ts
const found = resource((abort) => fetch(url(), { signal: abort }).then((r) => r.json()), {
  initialValue: [],
});
```

| Член | Тип | Описание |
| --- | --- | --- |
| `data` | `ReadonlySignal<T \| undefined>` | последний успешный ответ |
| `error` | `ReadonlySignal<unknown>` | причина отказа; сбрасывается при новом запросе |
| `loading` | `ReadonlySignal<boolean>` | запрос выполняется |
| `refetch` | `() => void` | повторить с теми же зависимостями |

Сигналы, прочитанные в `fetcher`, становятся зависимостями. Предыдущий запрос
отменяется через `AbortSignal`, устаревший ответ игнорируется. Синхронный
`fetcher` не поднимает `loading`. Эффект принадлежит текущему компоненту.

### `firstUpdate(source, cb)`

Вызывает `cb` на первое изменение источника; начальное значение пропускается,
после срабатывания эффект уничтожается.

## Владение эффектами

### `createRoot(fn)`

Корневой владелец для кода вне компонентов. `fn` получает `dispose` и возвращает
что угодно — обычно разметку.

### `createEffectScope()`

Локальный скоуп: `run(fn)` выполняет код с этим владельцем, `dispose()`
уничтожает всё созданное внутри.

### `withEffectHost(host, fn)` / `getEffectHost()` / `hostEffect(fn)`

Низкоуровневые примитивы владения. `hostEffect` создаёт эффект и отдаёт его
текущему владельцу; вне владельца предупреждает и создаёт независимый эффект.

## Типы

| Тип | Описание |
| --- | --- |
| `ReadonlySignal<T>` | читаемый источник: вызов + `peek` |
| `ReactiveSignal<T>` | `ReadonlySignal<T>` + `set`, `update` |
| `MaybeSignal<T>` | значение или сигнал (пропсы компонентов) |
| `MaybeReactive<T>` | значение, сигнал или обычная функция (дети, атрибуты, стили) |
| `SignalOptions<T>` | `{ equals?: EqualsFn<T> \| false }` |
| `EffectCb` | ручка эффекта с `destroy()` |
| `ElementChild` | строка, число, `boolean`, `null`, `undefined`, узел или функция |
| `FlowContent` | `ElementChild` или их массив |
| `ElementOptions<E>` | конфиг фабрики тега |
| `CustomElementOptions<B>` | конфиг фабрики компонента |
| `ComponentClass<P, E, S>` | то, что возвращает `defineComponent` |
| `ComponentBase<P, E, S>` | экземпляр компонента |
| `ComponentFactory<B>` | фабрика компонента |
| `ContextKey<T>` | ключ контекста |
| `Resource<T>` | результат `resource` |
| `ComponentStyles` | CSS компонента |
| `CustomTagName` | `` `${string}-${string}` `` |
